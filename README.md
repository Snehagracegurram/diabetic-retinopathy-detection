# 🩺 Quantum-Assisted CNN Architectures for Diabetic Retinopathy Detection

## 📌 Project Overview

This project focuses on detecting and classifying Diabetic Retinopathy using Quantum-Assisted Convolutional Neural Networks (CNN) and Hybrid Transfer Learning.

The system analyzes retinal images to assist in identifying Diabetic Retinopathy and its severity.

## 🎯 Objectives

- Detect Diabetic Retinopathy from retinal images.
- Apply CNN architectures and Hybrid Transfer Learning.
- Explore quantum computing techniques for image classification.
- Develop a user-friendly web interface for predictions.

## 🛠️ Technologies Used

| Category | Technologies |
|---|---|
| Programming Language | Python |
| Deep Learning | TensorFlow, Keras |
| Image Processing | OpenCV |
| Quantum Computing | Qiskit, IBM Quantum |
| Backend | Flask |
| Frontend | HTML, CSS, JavaScript |

## ⚙️ Methodology

1. Retinal image collection and preprocessing.
2. Image resizing and normalization.
3. CNN-based feature extraction.
4. Hybrid Transfer Learning.
5. Quantum feature processing.
6. Model prediction and classification.
7. Displaying results through a Flask web application.
